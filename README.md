Sum up the world's news of Thursday 19 November 2026 in one image. A
newspaper front page: one hero photograph — the first three-way
Trump–Xi–Putin summit in Shenzhen — above six dated, sourced stories,
so the day is clear from the image alone, with no news feed.

## The six stories in the image

1. **Trump, Xi and Putin meet in Shenzhen** — first three-way summit, on
   the APEC sidelines; nuclear arms, Ukraine and Iran on the table, no
   breakthrough expected. (BBC, CBS News, Japan Times)
2. **Gulf on edge** — US jets struck an IRGC missile site on Qeshm
   Island; Iran hit a US base in Kuwait and sites in Bahrain; a tanker
   burned in the Strait of Hormuz. (AP, TWZ)
3. **Crimea Bridge hit again** — Ukraine struck the bridge a third time
   in a week, hitting the rail link; traffic halted hours before the
   summit. (BBC, Meduza)
4. **Justice for the Rohingya** — the UN's top court (ICJ) rules on
   genocide claims against Myanmar.
5. **North Korea builds up** — the IAEA says Pyongyang expanded uranium
   enrichment at Yongbyon.
6. **Voyager 1, one light-day out** — NASA's probe becomes the first
   human-made object one light-day from Earth.

The hero photograph is AI-generated (three leaders seen from behind, so
no likeness is claimed); every headline and caption is typeset from the
reported facts above, so the text in the image is exact and legible.

## Run it

```sh
python3 main.py
# writes /output/entry.png (1024x1024 PNG, 464 KiB)
```

`main.py` (Python 3.13, standard library only, no network) copies the
bundled `entry.png` to `/output/entry.png`. Running it twice writes
identical bytes.
